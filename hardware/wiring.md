# stackdose 배선표 (8칸)

전원은 **5V 4A 어댑터 하나**입니다. 모든 GND는 하나로 묶습니다.
배선은 모두 **제어판의 만능기판**으로 모입니다. ESP32는 만능기판 옆 받침에 올려 두고 F-F 점퍼(30cm)로 만능기판 핀헤더와 연결합니다.

## 배치 (어디에 무엇이 있나)

| 부품 | 위치 |
|---|---|
| 만능기판 (DRV8833 ×2, 커패시터, 전원 분배), ESP32, DC 잭 | 제어판 (알약 스테이션 뒤, 탁자 위) |
| ULN2003 ×4 | 알약 바닥판, 알약 모듈 4개 각각의 바로 아래 |
| MCP23017 | 알약 바닥판 뒤쪽 가운데 |
| HX711 | 가루 바닥판 뒤쪽 왼편 (로드셀 옆) |
| 홀 센서 ×4 | 알약 모듈 바닥 밑 홈 (원판 자석 바로 아래) |

## 전원

| 출발 | 도착 | 비고 |
|---|---|---|
| 5V 어댑터 → DC 잭 | 만능기판 5V 레일 / GND 레일 | 터미널 블록 |
| 5V 레일 | ESP32 `5V` 핀 | ⚠ USB로 코드를 올릴 때는 이 선을 뽑으세요 |
| 5V 레일 | DRV8833 #1·#2 `VCC` | 모터 전원 |
| 5V 레일 | ULN2003 #1~#4 `+` | 알약 모터 전원 (점퍼로 MCP 옆까지 한 가닥, 거기서 4갈래) |
| ESP32 `3V3` | MCP23017 `VCC`·`RESET`, HX711 `VCC`, 홀 센서 4개 `+`, DRV8833 #1·#2 `EEP` | EEP를 안 이으면 DRV8833이 잠들어 **모터가 안 돕니다**. MCP23017 `RESET`도 3V3에 이어야 동작합니다 (보드에 이미 연결돼 있으면 생략 ★) |
| 1000µF 10V ×3 | DRV8833마다 `VCC`–`GND` 1개, DC 잭 옆 1개 | 긴 다리 = +, 띠 표시 = − |
| 100nF ×4 | 가루 모터마다 두 단자 사이에 납땜 | 모터 잡음이 ESP32를 리셋시키는 것을 막음 |
| 4.7kΩ ×2 | SDA–3V3, SCL–3V3 | I2C 풀업 (MCP 보드에 이미 있으면 생략해도 됨) |
| 10kΩ ×1 | nFAULT–3V3 | 풀업 |

## ESP32 핀 배정

부팅에 영향을 주는 핀(0, 2, 12, 15), 메모리 칩 핀(6~11), USB 통신 핀(1, 3)은 쓰지 않았습니다.
16·17번은 ESP32 모듈 종류(WROVER)에 따라 쓸 수 없어서 피했습니다.

| ESP32 | 연결 | 용도 |
|---|---|---|
| GPIO21 | MCP23017 `SDA` | I2C |
| GPIO22 | MCP23017 `SCL` | I2C |
| GPIO18 | HX711 `DT` | 무게 데이터 |
| GPIO33 | HX711 `SCK` | 무게 클럭 |
| GPIO25 | DRV8833 #1 `AIN1` | 가루 1 |
| GPIO26 | DRV8833 #1 `AIN2` | 가루 1 |
| GPIO27 | DRV8833 #1 `BIN1` | 가루 2 |
| GPIO13 | DRV8833 #1 `BIN2` | 가루 2 |
| GPIO32 | DRV8833 #2 `AIN1` | 가루 3 |
| GPIO23 | DRV8833 #2 `AIN2` | 가루 3 |
| GPIO4  | DRV8833 #2 `BIN1` | 가루 4 |
| GPIO19 | DRV8833 #2 `BIN2` | 가루 4 |
| GPIO5  | DRV8833 #1·#2 `ULT`(nFAULT) 묶어서 | 드라이버 오류 감지 (10kΩ 풀업. 부팅 때 HIGH여야 하는 핀이라 풀업과 맞음) |
| GPIO36 (VP) | 홀 센서 1 `S` | 알약 1 원점 (아날로그) |
| GPIO39 (VN) | 홀 센서 2 `S` | 알약 2 원점 |
| GPIO34 | 홀 센서 3 `S` | 알약 3 원점 |
| GPIO35 | 홀 센서 4 `S` | 알약 4 원점 |

홀 센서 4개는 모두 ADC1 핀이라 와이파이를 켜도 읽힙니다. 자석이 없을 때 약 1.65V이고, 자석이 오면 위나 아래로 크게 움직입니다. 기준값은 처음에 한 번 재서 코드에 넣습니다.

## MCP23017 → ULN2003 (알약 모터 4개)

주소는 0x20입니다 (A0·A1·A2를 GND에 연결).

| MCP23017 | ULN2003 | 알약 칸 |
|---|---|---|
| GPA0~GPA3 | #1 `IN1~IN4` | 알약 1 |
| GPA4~GPA7 | #2 `IN1~IN4` | 알약 2 |
| GPB0~GPB3 | #3 `IN1~IN4` | 알약 3 |
| GPB4~GPB7 | #4 `IN1~IN4` | 알약 4 |

28BYJ-48은 ULN2003 보드의 흰 커넥터에 그대로 꽂습니다. 배출하지 않을 때는 네 핀을 모두 LOW로 둡니다.

## 선 길이 · 종류 (20% 여유 포함)

| 구간 | 가닥 | 한 가닥 길이 | 선 | 지나는 길 |
|---|---|---|---|---|
| 가루 모터 1·2 (뒤쪽) → 만능기판 | 2 × 2 | 45cm | 단선 0.6 | 모터 밑 상판 구멍(Ø9) → 가장 가까운 기둥 따라 아래로 → 가루 바닥판 뒤 가장자리 케이블 타이 → 제어판 |
| 가루 모터 3·4 (앞쪽) → 만능기판 | 2 × 2 | 65cm | 단선 0.6 | 같은 길, 바닥판 옆 가장자리를 따라 뒤로 |
| 로드셀 → HX711 | 4 | 로드셀 기본 선 (약 20cm ★) | — | 바로 옆. HX711 `E+ E− A− A+` 에 납땜 (빨강 검정 하양 초록이 보통, 색은 확인) |
| HX711 → 만능기판 | 4 | 55cm | 단선 0.6 | 가루 바닥판 뒤 가장자리 → 알약 바닥판 뒤 → 제어판 |
| 홀 센서 (뒤쪽 2개) → 만능기판 | 3 × 2 | 45cm | 단선 0.6 | 모듈 바닥 홈 → 치마 안 → 상판 전선 구멍(20×12) → 기둥 따라 아래 → 제어판 |
| 홀 센서 (앞쪽 2개) → 만능기판 | 3 × 2 | 60cm | 단선 0.6 | 같은 길 |
| 28BYJ-48 → ULN2003 | (모터 기본 선) | 약 25cm ★ | — | 상판 전선 구멍 → 바로 아래 ULN2003 |
| ULN2003 ×4 → MCP23017 | 4 × 4 + 전원 | 30cm | F-F 점퍼 | 알약 바닥판 위, 케이블 타이 구멍 따라 |
| MCP23017 → 만능기판 (SDA, SCL, 3V3, GND, 5V) | 5 | 30cm (2개 이어 60cm) | F-F 점퍼 → 제어판에서 만능기판 핀헤더 | 알약 바닥판 뒤 가장자리 |
| ESP32 → 만능기판 | 약 20 | 30cm | F-F 점퍼 | 제어판 위 |

단선은 "3색 점퍼용 단선 0.6파이 [1미터단위]"입니다. 상품 설명에 따르면 1개를 사면 빨강·검정·흰색이 1m씩 꼬여서 옵니다.

| 색 | 쓰는 곳 | 필요 길이 |
|---|---|---|
| 빨강 | 모터 +, HX711 VCC, 홀 센서 + | 약 4.9m |
| 검정 | 모터 −, HX711 GND, 홀 센서 − | 약 4.9m |
| 흰색 | HX711 DT·SCK, 홀 센서 S | 약 3.2m |

가장 많이 쓰는 색이 약 4.9m라서 **6개**를 사세요 (색마다 6m). 상품 설명에 "부분 절단될 수 있다"고 되어 있어서 1m를 더 잡았습니다.
홀 센서 선은 세 가닥 꼬인 그대로 쓰면 됩니다.

⚠ **ESP32는 점퍼를 먼저 다 꽂고 받침에 올리세요.** 받침은 긴 두 변이 열려 있어서, 꽂은 선이 옆으로 빠져나갑니다. 받침에 먼저 올리면 밑의 핀에 손이 안 들어갑니다.
