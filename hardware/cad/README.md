# stackdose · 3D 설계 (8칸: 가루 4 + 알약 4)

모든 치수는 [config.scad](config.scad) 한 곳에 있습니다. ★가 붙은 값은 **추정치**라, 부품이 도착하면 아래 측정표대로 재서 고칩니다. 숫자를 고친 뒤에는 `python check.py`로 다시 검사합니다.

OpenSCAD에서는 **파일 → 열기**로 `assembly.scad`를 여세요. 코드를 복사해서 새 창에 붙이면 `include` 파일을 못 찾습니다.

## 구조

- **가루 스테이션 (왼쪽, 210×210mm):** 스크류 4개가 컵을 중심으로 X자로 모이고, 출구 4개가 컵 입구 안으로 바로 떨어집니다. 모터는 JGA25-370이고, 반원 받침과 덮개 띠로 감싸 약 0.3mm 눌러 잡습니다. 가루통은 깔때기(호퍼) 위에 얹습니다. 컵은 로드셀 저울 위에 있어서, 무게를 보면서 스크류를 돌리고 목표량이 되면 멈춥니다.
- **알약 스테이션 (오른쪽, 205×205mm):** 원판 모듈 4개가 2×2로 놓입니다. 원판에는 칸이 3개라서 120° 돌 때마다 한 알이 나갑니다. 원판 밑의 자석과 바닥의 홀 센서로 원점을 찾습니다. 각 출구에서 비스듬한 미끄럼관을 타고 컵까지 내려갑니다.
- **제어판 (알약 스테이션 뒤):** 만능기판, ESP32, DC 잭. 배선은 [../wiring.md](../wiring.md)에 있습니다.
- 두 스테이션과 제어판은 따로 서 있고, 전선만 오갑니다. 컵은 두 스테이션 모두 **4.5mm 들어 올려 앞으로** 뺍니다.

## 파일

| 파일 | 부품 |
|---|---|
| `coupon.scad` | 공차 쿠폰 (가장 먼저 출력) |
| `powder.scad` | 가루 모듈: 아래 반쪽 관 + 모터 받침, 위 반쪽 관 + 칼라, 모터 덮개 띠, 호퍼, 스크류 |
| `pill.scad` | 알약 모듈: 치마, 바닥, 원판, 덮개 + 호퍼 (미끄럼관 모양은 여기, 출력은 알약 상판에 붙어서) |
| `scale.scad` | 저울: 로드셀 받침(과부하 멈춤대 포함), 컵 쟁반, 간격 와셔 |
| `frame.scad` | 스테이션별 바닥판(보드 받침 포함)·상판(알약 쪽은 미끄럼관 포함), 기둥, 핀 |
| `electronics.scad` | 제어판(만능기판·ESP32·DC 잭 받침 한 판), 바닥판에 붙는 보드 받침 모양 |
| `layout.scad` | 모듈 배치 계산 |
| `assembly.scad` | 전체 조립 미리보기 |
| `check.py` · `overhang.py` | 자동 검사 (아래) |

## 자동 검사가 보는 것

`python check.py` 하나로 전부 돌아갑니다.

| 검사 | 내용 |
|---|---|
| parts | 부품마다 렌더 오류 없음, 출력판(220×220×250) 안, **한 덩어리** (떨어진 조각 없음) |
| rest | 알약 원판이 멈춰 있을 때 칸이 출구 위에 걸치지 않음 |
| clash | 조립 상태에서 부품끼리 겹침 없음 (155쌍). 컵 꺼내는 길, 호퍼·가루통, 홀 센서 포함. 모터 덮개 띠의 조임만 의도한 겹침으로 허용 |
| overhang | `python overhang.py` — 서포트 없이 뽑을 수 없는 면이 있는지 |

## 출력 순서

큰 판은 작은 부품이 전부 맞는 걸 확인한 **맨 마지막**에 뽑습니다. 모듈은 **1벌 먼저** 뽑아 돌려 보고, 맞으면 나머지 3벌을 뽑습니다.

| 순서 | 부품 | 개수 | 확인할 것 |
|---|---|---|---|
| 1 | coupon | 1 | 아래 "쿠폰 읽는 법" → config 값 고치고 `check.py` |
| 2 | auger · powder_top · powder_block · powder_strap · powder_hopper | 1씩 | 스크류가 관 안에서 부드럽게 도는지, 모터가 받침에 꽉 물리는지 |
| 3 | pill_disk · pill_skirt · pill_floor · pill_cover | 1씩 | 원판이 도는지, 캡슐이 칸에 눕는지, 자석이 홀 센서 위에서 읽히는지 |
| 4 | scale_pedestal · scale_tray · scale_spacer | 1·1·2 | 로드셀 볼트가 맞는지 |
| 5 | pins | 1판 | 핀이 모듈·상판 구멍에 헐겁지 않게 들어가는지 |
| 6 | 2번 · 3번의 나머지 | 3벌씩 | |
| 7 | ctrl_plate | 1 | ESP32·만능기판이 들어가는지 |
| 8 | post | 14 | 가루 7 + 알약 7. 눕혀서 출력 |
| 9 | base_powder · deck_powder · base_pill · deck_pill | 1씩 | 가장 오래 걸림. 바닥판에 보드 받침, 알약 상판에 미끄럼관이 붙어 있음 |

출력 설정(PLA, Ender-3 SE): 레이어 0.2mm, 벽 3줄, 채움 25%, **서포트 없음**. STL은 출력 방향으로 들어 있습니다.

## 쿠폰 읽는 법

| 줄 | 표시 | 고를 칸 | 바꿀 값 |
|---|---|---|---|
| 1 | C | 8mm 핀이 **돌지만 흔들리지 않는** 칸 | `clear` = 0.1 × 칸 번호 |
| 2 | J | JGA25-370 축이 **손으로 꽉 끼는** 칸 | 스크류 허브 여유 (알려 주세요) |
| 3 | B | 28BYJ-48 축이 **손으로 꽉 끼는** 칸 | 원판 허브 여유 (알려 주세요) |
| 4 | M | M3 나사가 **힘 없이 지나가는 가장 작은** 칸 | `m3_hole` = 3.1 + 0.1 × 칸 번호 |
| 5 | H | M3 너트가 **눌러야 들어가고 안 빠지는** 칸 | `m3_nut_af` = 5.5 + 0.1 × 칸 번호 |

C 줄의 값(`clear`)이 핀·기둥 돌기·치마 턱의 헐거움을 모두 정합니다.

## 나사 개수 (20개)

나사는 **힘을 받는 곳에만** 씁니다. 나머지는 끼우거나 얹습니다.

| 어디 | 나사 | 너트 |
|---|---|---|
| 가루 모터 덮개 띠 (모터 4개 × 2) | M3x12 × 8 | 8 |
| 알약 모터 (4개 × 2) | **M3x5** × 8 | 8 |
| 로드셀 고정 끝 / 쟁반 끝 | M5x15 × 2 / M4x12 × 2 | (로드셀 나사산에 바로) |

알약 모터 나사는 반드시 **M3x5**여야 합니다. 더 길면 끝이 원판 밑에 닿습니다.

## 나사 없이 붙는 곳

| 어디 | 방법 |
|---|---|
| 기둥 ↔ 바닥판 · 상판 | 기둥 양 끝 네모 돌기를 판의 네모 구멍에 끼움. 상판은 기둥 위에 얹힘 |
| 가루 모듈 ↔ 상판 | 상판 핀 구멍에 핀 2개를 넣고 모듈을 얹음 |
| 가루 모듈 위 관 ↔ 아래 관 | 핀 2개. 위에 호퍼와 가루통이 얹혀서 눌림 |
| 알약 모듈 ↔ 상판 | 핀 2개 |
| 알약 치마 ↔ 바닥 | 치마 윗면 턱에 바닥의 홈이 끼워짐 (돌지 않게 키 1개) |
| 알약 미끄럼관 | 상판과 한 덩어리로 출력 |
| 저울 받침 ↔ 바닥판 | 핀 2개 |
| 보드 (ULN2003 ×4, MCP23017, HX711) | 바닥판에 붙은 받침에 올리고 케이블 타이 하나 |
| ESP32 · 만능기판 · DC 잭 | 제어판 받침에 올림 / 홈에 밀어 넣음 / 케이블 타이 |

핀은 `pins` 한 판에 30개(26개 + 여분 4)가 들어 있습니다.
